## MACHINE LEARNING THEORY AND LAB MATERIAL

In this repo I will store everything related to laboratories and theory classes for the course of Machine learning in the Master's Degree on Physics of Data at UniPD 2026.

#### Target skills and knowledge:

The aim of this course is to provide the fundamentals and basic principles of the learning problem as well as to introduce the most common machine learning algorithms. The course will be complemented by hands-on experience.


#### Course syllabus:

    1- Statistical machine learning: defining machine learning tasks, providing performance 
    guarantees, selecting the best models and algorithms.
    2- Classical machine learning: linear classification and regression, perceptrons, Support
    Vector Machines, random forests
    3- Deep learning: gradient descent, neural network models, backpropagation, Convolutional
    Neural Networks
    4- Unsupervised learning: clustering models and metrics, linkage-based clustering, 
    clustering algorithms, Principal Component Analysis
    5- Reinforcement learning: Markov Decision Processes, on- and off-policy learning, 
    Q-learning, SARSA

#### Laboratories:

    0- Introduction to Python (Oct. 20)
    1- Model selection and validation (Oct. 27)
    2- Perceptrons and regression (Nov. 3)

    4- Random forests (Nov. 17)
    5- Backpropagation and neural networks (Dec. 1)
